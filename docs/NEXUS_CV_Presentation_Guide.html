1. Executive Vision & Problem Statement

  • Resume Overload: Enterprise openings receive hundreds of resumes per requisition. Recruiters spend over 75% of their working hours manually scanning unqualified documents.
  • The "Black-Box" AI Dilemma: Traditional ATS keyword scrapers either blindly reject qualified candidates or use opaque models with zero hiring transparency.
  • Fragmented Workflows: Disconnect between public career boards and internal recruiter pipelines leads to duplicate data entry and candidate drop-off.
  • The NEXUS-CV Solution: An autonomous, explainable ATS delivering dual-channel candidate sourcing, multi-dimensional semantic vector scoring, and an immutable 6-stage recruiter workflow.

2. System Architecture & Technical Highlights

  • Client Layer (React 18 + Vite): Responsive Single-Page Application (SPA) with dual access: Public Career Portal (/careers) and Secure Recruiter Dashboard (/dashboard).
  • API Gateway (Java 17 + Spring Boot 3.3): Enterprise orchestration handling authentication (HMAC-SHA256 JWT), role management, transactional persistence, and resume storage.
  • AI Microservice (Python 3.10 + FastAPI): Sub-second NLP pipeline running Scikit-learn TF-IDF vectorization, Cosine similarity calculation, and dimensional feature extraction.
  • Cloud Infrastructure: Unified multi-stage Docker container deployed 24/7 on Render cloud with automated GitHub CI/CD webhooks.

3. Present Capabilities (v1.0 Live Features)

A. Dual Sourcing Channels

  • Public Candidate Career Portal: Clean, mobile-ready portal where candidates browse live requisitions and submit applications with PDF/DOCX resumes.
  • Recruiter Batch Screening: Recruiters can ingest dozens of resumes simultaneously directly into any job requisition for automated ranking.

B. Multi-Dimensional Explainable Scoring

  • Semantic Vector Space: Evaluates candidate qualifications against job descriptions using TF-IDF and Cosine similarity.
  • Dimensional Breakdown: Calculates individual sub-scores for Required Skills, Preferred Skills, Experience Alignment, and Education.
  • Transparent Match Explanations: Generates human-readable summaries highlighting candidate strengths and missing requirements.

C. Complete Recruiter ATS Pipeline

  • Role Lifecycle: Draft, Publish, Pause, Close, and Delete requisitions with transactional integrity.
  • 6-Stage Candidate State Machine: Applied, Screening, Interview, Offered, Hired, and Rejected.
  • Immutable Audit History: Every status transition and recruiter note is logged with timestamps and user attribution.

4. Future Scope & Roadmap

Phase 2: Near-Term Enhancements (v2.0)

  • Generative AI Interview Generator: Automatically produce role-specific technical interview questions targeting candidate resume gaps.
  • Multi-Modal OCR Ingestion: Tesseract / Vision AI support to parse scanned images and portfolio PDFs.
  • Automated Email Triggers: Automated receipt, invitation, and decision emails via SendGrid / AWS SES.
  • Cloud S3 Bucket Storage: Offload file storage to encrypted AWS S3 buckets with pre-signed URLs.

Phase 3: Long-Term Enterprise Scope (v3.0)

  • AI Video Interview Evaluation: Asynchronous video response analysis for structured communication and problem-solving.
  • Enterprise ATS Connectors: Two-way synchronization plugins for Workday, BambooHR, and Greenhouse.
  • Fairness & Bias Auditing: Blinded demographic screening mode ensuring diversity and regulatory compliance.
